# Task 4: Classification with Logistic Regression

## Objective
Build a binary classification model using Logistic Regression.

## Dataset
Breast Cancer Wisconsin Dataset from Scikit-learn.

## Tools and Libraries
- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Steps Performed
1. Loaded and explored the dataset.
2. Checked missing values.
3. Split data into training and testing sets.
4. Standardized the features.
5. Trained a Logistic Regression model.
6. Evaluated the model using a confusion matrix, precision, recall, and ROC-AUC.
7. Plotted the ROC curve and sigmoid function.
8. Tested threshold tuning.

## Results
- Precision: 98.61% (threshold 0.5)
- Recall: 98.61% (threshold 0.5)
- ROC-AUC Score: 0.9954
- Accuracy: 98.25%

## Conclusion
The Logistic Regression model performed very well on the test dataset. This task helped me understand binary classification, sigmoid functions, evaluation metrics, and threshold tuning.
